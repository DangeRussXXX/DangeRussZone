# Technical Education Portfolio — starter homepage

## Install in your existing GitHub Pages repository

Copy the entire `teaching-portfolio` folder into the root of your `DangeRussZone` repository, preserving these paths:

- `teaching-portfolio/index.html`
- `teaching-portfolio/assets/css/style.css`
- `teaching-portfolio/assets/js/main.js`

Commit and push to the branch used by GitHub Pages. Assuming your current Pages setup publishes from the repository root, the new site will be available at:

https://dangerussxxx.github.io/DangeRussZone/teaching-portfolio/

This is a separate site and does not overwrite your existing About page.

## What this first version includes

- Responsive homepage with mobile menu
- About, experience, projects, teaching approach, and contact sections
- Abstract vector illustrations made with HTML/CSS/SVG (not photographs of actual projects)
- Accessible skip link, heading hierarchy, and keyboard-focus styling

## Before using in an application

- Verify every factual statement and update project status descriptions as work progresses.
- Add authentic project screenshots, photographs, and a lesson example.
- Optionally add a verified downloadable resume PDF and link to it from the homepage.
- Avoid publishing student information or institution-confidential materials.
- The teaching approach expresses a proposed instructional philosophy, not a claim of prior electrical instructor employment.
